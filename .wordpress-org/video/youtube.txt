Turn plain client reviews into a beautiful 3D testimonial showcase on your WordPress site – free.

Ultimate 3D Testimonial Slider lets you add testimonials, design a slider visually in the Shortcode Builder with a live preview, and place it anywhere with one shortcode. Works with any theme and page builder that supports shortcodes.

⬇️ Download free on WordPress.org:
https://wordpress.org/plugins/ultimate-3d-testimonial-slider/

✨ FEATURES
• 5 layouts: 3D slider, grid, list, masonry and an endless scrolling ticker
• 8 card styles: Classic, Modern, Soft tint, Speech bubble, Elegant, Glass, Dark and Split
• 7 slider effects: 3D coverflow, slide, fade, cards, 3D cube, flip and creative
• Star ratings (1–5) – shown only on testimonials where you set them
• Shortcode Builder with live preview – save sliders and reuse them with [uts id="1"]
• Autoplay, loop, speed, arrows and dots – loop works even with a few testimonials
• Colors, corner radius, columns, excerpt length and image size
• Categories, to show different testimonials on different pages
• Lightweight: no jQuery, CSS and JS load only on pages that use the shortcode
• Accessible: respects visitors who prefer reduced motion

🚀 HOW TO USE
1. Install "Ultimate 3D Testimonial Slider" from Plugins → Add New
2. Add your testimonials (name, quote, photo, position and an optional star rating)
3. Create a slider in Ultimate 3D Testimonial Slider → Shortcode Builder
4. Copy the shortcode and paste it into any page or post
