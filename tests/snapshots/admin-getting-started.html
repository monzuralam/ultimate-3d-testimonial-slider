How to use

1 Add a testimonial
  1. Go to Ultimate 3D Testimonial Slider → Add Post.
  2. Title: the client's name, e.g. "Jane Cooper".
  3. Content: what the client said. Keep it short; the excerpt length in Settings trims long ones.
  4. Client Featured Image: the client's photo. A square image of at least 160 × 160 px looks best, since it is shown as a circle.
  5. Position & Company Name (below the editor): e.g. "CEO, Acme Inc."
  6. Order (Page Attributes box): lower numbers show first. Leave it at 0 to keep the default order.
  7. Click Publish. Only published testimonials are shown.
2 Organize with categories (optional)

Categories let you show different testimonials in different places, for example "Web Design" clients on one page and "SEO" clients on another.

  1. Create categories under Category in the plugin menu, or tick them in the Category box while editing a testimonial.

3 Show testimonials on your site

Everything works with one shortcode. Copy it, then paste it where you want the testimonials:

Block editor (Gutenberg)

Click +, search for "Shortcode", add the Shortcode block and paste [uts].

Classic editor

Paste [uts] on its own line in the content.

Elementor and other page builders

Drag in the "Shortcode" widget/element and paste [uts].

Sidebar or footer widget

Appearance → Widgets (or Editor for block themes): add a Shortcode block and paste [uts].

In a theme template file (for developers):

<?php echo do_shortcode( '[uts]' ); ?>
4 Customize the design

There are two levels, and you can mix them:

  • Settings page: the defaults for every [uts] on your site, such as layout, effect, autoplay and colors.
  • Shortcode attributes: change one slider only. Any setting can be used as an attribute with the same name, and it wins over the Settings page.

5 Shortcode reference
Attribute What it does Default
type Layout: slider, grid or list. slider
count How many testimonials to show. 0 shows all. 0
category Only show testimonials from this category (use the category slug). —
excerpt_length Words of the testimonial to show. 0 shows the full text. 50
image_size Image size: thumbnail, medium, large or full. large
effect Slider effect: coverflow, slide, fade or cards. coverflow
speed Transition speed in milliseconds. 300
autoplay Move to the next slide automatically: true or false. false
autoplay_delay Time between slides when autoplay is on, in milliseconds. 3000
loop Go back to the first slide after the last one: true or false. false
pagination Show dots under the slider: true or false. true
navigation Show previous/next arrows: true or false. false
coverflow_rotate Coverflow only: how far side slides turn, in degrees. 50
coverflow_depth Coverflow only: how far side slides sit back. 100
coverflow_stretch Coverflow only: space between slides (negative overlaps them). 0
show_image Show the client photo: true or false. true
show_title Show the client name: true or false. true
show_designation Show the position and company: true or false. true
grid_columns Grid only: columns on desktop, 1 to 6. 3
accent_color Color of the dots and arrows, e.g. #2271b1. —
text_color Text color of the cards. —
background_color Background color of the cards. —
border_radius Card corner radius in pixels. 0

"Default" shows your current Settings value, used when the attribute is left out.

? Tips & troubleshooting
Nothing shows up on the page
Check that the testimonials are published, that the category slug is spelled exactly right, and that the shortcode is not inside a code block. Clear your caching plugin after changes.
More than one slider on a page
Supported. Each [uts] works on its own with its own attributes.
Changing the order
Set "Order" in the Page Attributes box of each testimonial. Lower numbers come first.
Autoplay or loop looks odd with few testimonials
Loop needs at least 3 testimonials to look smooth; add more or turn loop off.
Matching my theme
Use the Style tab in Settings for colors and corner radius. For more, target .ucs-container and .ucs-item in your theme's custom CSS.
